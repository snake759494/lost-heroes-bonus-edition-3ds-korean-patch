# 로스트 히어로즈 보너스 에디션 (3DS) 비공식 한글패치

닌텐도 3DS 일본판 eShop 다운로드판 **ロストヒーローズ ボーナスエディション** (타이틀 ID `0004000000147000`)의 비공식 한국어 패치입니다. 이 저장소에는 제작 도구와 기술 문서만 있습니다. 패치 파일(xdelta)은 [Releases](../../releases)에서 받을 수 있습니다. 게임 원본, 일본어 원문, 번역 대본은 포함하지 않습니다.

## 적용 방법
1. 아래 해시와 일치하는 **원본 eShop CIA**를 준비합니다. 다른 덤프에는 적용할 수 없습니다.
   - PowerShell: `Get-FileHash -Algorithm MD5 -LiteralPath '.\Lost Heroes (Bonus Edition) (Japan) (eShop).cia'`
2. xdeltaUI 같은 도구로 원본에 `LostHeroes_BonusEdition_3DS_KO_v1.1.xdelta`를 적용합니다.
   - 명령줄: `xdelta3 -d -s "Lost Heroes (Bonus Edition) (Japan) (eShop).cia" LostHeroes_BonusEdition_3DS_KO_v1.1.xdelta "Lost Heroes (Bonus Edition) (Korean).cia"`
3. 만들어진 `.cia`를 Azahar 같은 3DS 에뮬레이터에 설치해 실행합니다.
   - `.3ds`(CCI)가 필요하면 makerom으로 변환합니다: `makerom -ciatocci "Lost Heroes (Bonus Edition) (Korean).cia"`

## 주의
- **패치가 원본만큼 큽니다(약 1GB).** 원본 CIA는 암호화되어 있고 결과물은 복호화 상태(NoCrypto)라서, 차분 파일에 거의 모든 데이터가 들어갑니다. 결과 CIA는 서명되지 않은 상태입니다.
- **에뮬레이터(Azahar) 기준으로 검증했습니다.** 실기(커스텀 펌웨어)에서는 확인하지 않았습니다.

## 한글화 내용
- **게임 텍스트 전체:** MBB 761개, 고유 문장 18,017개. 대사, 이벤트, 퀘스트, 아이템·스킬·칩·캐릭터·적 이름과 설명, 메뉴, 전투·시스템 메시지, 튜토리얼이 포함됩니다.
  - 팩(2NBF) 안에 들어 있는 사본 약 490개도 함께 교체했습니다.
- **글꼴:**
  - 게임 자체 비트맵 폰트 2종(14×16, 10×10)을 다시 그렸습니다. 기호·가나 영역(0~362번)은 그대로 두고, 한자 영역에 번역에 쓰인 한글 1,184자를 배치했습니다.
  - 띄어쓰기는 반각 공백, 영숫자는 반각 문자를 써서 가변폭으로 출력됩니다.
  - 대사는 대화창 폭(약 336px)에 맞춰 다시 줄바꿈했습니다.
- **그림 글자 84종:**
  - 타이틀 로고 「로스트 히어로즈」, 타이틀 메뉴, 저작권 표기
  - 경고문, 지역명, 던전 타이틀
  - 거점·전투·캠프·공용·맵 UI, 미니게임, 세이브 화면
  - 튜토리얼 설명 화면 16장, 오프닝 자막 이미지
- **엔딩 스태프롤:** 전용 폰트를 한글로 다시 만들었습니다. 역할은 번역하고, 인명은 일본어 읽기를 한글로 표기했습니다.
- **오프닝 동영상:** 마지막 「ロストヒーローズ」 로고 장면을 「로스트 히어로즈」로 합성해 다시 인코딩했습니다.
- **고유명사:** 울트라맨·가면라이더·건담 시리즈의 국내 통용 표기를 따랐습니다.

## 그대로 둔 것
- 튜토리얼 캡처 화면 속 5~6px 크기의 아주 작은 글자 일부(버튼 안내 등)
- 오프닝 동영상의 로고가 날아드는 애니메이션 구간(약 1초)
- 영문 스태프롤과 영문 그림 글자
- 변수 뒤 조사: 받침 여부를 알 수 없어 「은(는)」 같은 표기를 쓴 곳이 있습니다.
