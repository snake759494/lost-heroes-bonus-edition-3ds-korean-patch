# 기술 문서

## 원본
- **형식:** eShop CIA. 콘텐츠 0은 게임, 콘텐츠 1은 전자 설명서입니다. 타이틀키로 암호화돼 있습니다.
- **복호화:** Batch CIA 3DS Decryptor의 `decrypt.exe`로 콘텐츠별 NCCH를 복호화합니다.
- **재포장:** `makerom -f cia -ignoresign`으로 다시 묶습니다. 결과물은 NoCrypto이며 서명되지 않은 상태입니다.
- **RomFS:** IVFC 계층을 새로 계산해 다시 만들고(`tools/build.py`, `tools/mkncch.py`), ExeFS(code)는 수정하지 않습니다.

## 컨테이너
- **`.cmp`:** `COMP` + LZ11(Nintendo 0x11) 압축입니다(`tools/lz11.py`). 다시 넣을 때는 리터럴만으로 인코딩합니다.
- **`*_pk.cmp`:** `2NBF` 팩입니다(`tools/nbf.py`).
  - 헤더는 `2NBF`, 개수, 데이터 시작 위치, 정렬 단위입니다.
  - 항목은 0x8C바이트로, 이름 0x80바이트와 오프셋·?·크기로 이뤄집니다.
  - **주의:** 이벤트 팩, 전투 팩, `Graph/STARTUP_pk.cmp` 안에 MBB와 폰트 사본이 들어 있습니다. 개별 파일과 사본을 함께 교체해야 합니다.

## 텍스트 (MBB)
- **구조:** `TBB1` 안에 `MTBL` 테이블이 여러 개 있습니다(`tools/mbbw.py`).
  - 각 테이블의 문자열 오프셋은 **개수+1개**입니다. 마지막 항목도 문자열입니다.
  - 홀수 오프셋은 그대로 보존합니다.
- **문자 코드:** u16 하나가 폰트 셀 번호+1을 뜻합니다. 값 0은 문자열 끝입니다.
  - 0x8001은 줄바꿈, 0x8002는 페이지 넘김입니다.
  - 0x8069~0x8092 + 전각 공백 n개는 변수(캐릭터명·수치) 자리입니다. 번역 파일에서는 `⟦8073:11⟧`처럼 토큰으로 표기했습니다.
- **원문 복원:** 폰트 텍스처를 일본어 OCR(Windows.Media.Ocr)로 읽어 문자표를 만들었습니다.
  - 기호·가나는 Shift-JIS 순서로 배열돼 있습니다.
  - 한자는 원문에 등장한 순서로 배열돼 있습니다.
  - OCR은 문맥 투표로 식별하고, 나머지 약 330자는 템플릿 매칭과 육안 검수로 정했습니다(`tools/align.py`, `tools/vote.py`, `tools/combine.py`).
- **번역 단위:** 중복을 제거해 고유 문장 18,017개를 만들었습니다(`tools/units.py`).

## 폰트
- **Font14** (256×512 A4, 4장): 셀 14×16, 18열입니다.
- **Font10** (2장): 셀 **10×10**, 25열입니다. 화자 이름표에 쓰입니다.
- **배치:** 0~362번 셀(공백·전각 영숫자·가나·반각 ASCII·기호)은 원본 그대로 둡니다. 363번 이후에 한글을 빈도순으로 그렸습니다(`tools/kbuild.py`, `tools/kglyph.py`).
- **글자 폭:** 게임은 글리프 잉크 폭+2px의 가변폭으로 그립니다.
  - 234번 셀(반각 공백)은 약 5px로 그려지므로 띄어쓰기에 씁니다.
  - 대사는 대화창 폭 336px·2줄을 기준으로 다시 줄바꿈합니다(`tools/wrap.py`).

## 그림 글자
- **텍스처:** `GFPT` 안에 `CTPK`가 있습니다(`tools/ctpk.py`). 형식은 RGBA4·5551·8, A8, A4입니다.
  - 인코딩: `tools/imgenc.py`. 입력은 위아래를 뒤집은 이미지이고, 원본과 바이트 단위로 왕복 검증했습니다.
- **조각 좌표:** 레이아웃 `GTSF` 안의 `GFUV` 블록에 텍스처별 조각 좌표(x,y,w,h, u16)가 있습니다(`tools/gfuv.py`). 게임은 이 조각 단위로 잘라 배치하므로, 조각 영역 안에 한국어를 그립니다.
- **렌더:** 사양서(`docs/IMAGE_GUIDE.md`)대로 렌더합니다(`tools/imgko.py`).
  - 원래 글자는 지웁니다. 투명 배경이면 투명으로, 불투명 배경이면 배경색으로 채웁니다.
  - 원래 글자색(세로 그라데이션 포함)과 외곽선을 추출해 다시 그립니다.
- **삽입:** 같은 텍스처를 쓰는 모든 팩에 넣습니다(`tools/texbuild.py`).

## 스태프롤
- `Table/StaffRoll/StaffRoll.mbb`는 전용 폰트 `Font/FontStaff.cmp`(256×512 A4)의 셀 번호를 씁니다.
- 셀 크기는 256/17(약 15.06)×16px이고 17열입니다. 글자는 원문 등장 순서로 배열돼 있습니다.
- 한글 글리프를 새로 그리고 문자열을 다시 인코딩했습니다(`tools/staffbuild.py`).

## 오프닝 동영상
- **형식:** `Movie/opening.moflex`는 MobiClip 400×240 영상이고, 영상·음성 두 스트림으로 구성되며 색인 스트림이 없습니다. 색공간은 YCgCo입니다(`tools/ycc.py`).
- **로고 교체:** 2918~3069프레임(로고가 멈춰 있는 구간과 사라지는 구간)에 한글 로고를 합성했습니다(`tools/movlogo.py`).
  - 원래 글자색 계열 픽셀만 지우고, 한글 글자와 발광 효과를 그렸습니다.
  - 페이드 구간에는 밝기 비율을 반영했습니다.
- **재인코딩:** `tools/mobi transcode`(`MOBI_NOBUDGET=1`)로 다시 인코딩하고 `tools/mux.py`로 다시 조립합니다.

## 그 밖에
- 컷신 3D 모델 텍스처(CGFX `TXOB`) 1,124장은 OCR로 검사했고, 일본어 글자가 없음을 확인했습니다(`tools/cgfxdump.py`).
