# 로스트 히어로즈 이미지(텍스처) 한글화 작업 지침

작업 폴더: 저장소 루트(bash에서도 같은 위치). 모든 파일은 이 폴더 안에만 만들 것(임시 파일은 `tmp_<내이름>/` 하위, 끝나면 삭제).
외부 번역기 금지. 직접 번역. 용어는 `tr/glossary.json`(일본어→한국어) 표기를 따른다. 게임: 울트라맨·가면라이더·건담 크로스오버 RPG.

## 자료
- `texdump/<md5>.png` : 원본 텍스처(RGBA). `texidx.json` : md5 → {fmt,w,h,name,refs}.
- `uv.json` : 텍스처별 조각 좌표 목록 [x,y,w,h] (조각 번호 = 리스트 인덱스). 게임은 이 조각 단위로 잘라 화면에 배치한다.
- `ov/<NN>_<hash8>.png` : 조각 테두리+번호가 그려진 확대 이미지(빨강=OCR이 일본어 감지, 하늘색=기타). `ov/order.json`에 목록.
- `python -I tools/lsr.py <hash8> ...` → `o.txt`에 조각별 좌표와 OCR 결과(일본어) 출력.
- `python -I tools/rects.py <hash8>` : 조각 좌표 출력.
- `python -I tools/crop.py <hash8> x0,y0,x1,y1 <배율> [texdump|imgout]` → `zc.png` (5px마다 빨간 눈금, 좌표 확인용).
- `python -I tools/prof.py <hash8> x0,y0,x1,y1 <밝기임계>` : 밝은 글자 줄의 y범위/x범위 출력.

## 사양서 형식 (각자 자기 파일 `spec_<이름>.txt`에 작성)
```
@<hash8>
<조각번호 또는 x,y,w,h> | <한국어> | <옵션(쉼표구분, 생략가능)>
```
- 지정한 영역의 원래 글자를 지우고(투명 배경이면 투명으로, 불투명 배경이면 주변색으로 메움) 한국어를 원래 글자 색/외곽선/세로 그라데이션을 자동 추출해 그린다. 높이는 원래 글자 높이에 맞추고, 폭이 넘치면 가로로 압축한다.
- 줄바꿈은 `\n` (역슬래시 n 두 글자).
- 옵션: `al=l|c|r`(정렬; 투명배경 기본 l, 불투명 기본 c), `bg=opaque`(불투명 배경으로 처리·지우기는 주변색 메움), `font=xb|bold|heavy|reg|serif`(기본 xb=NanumSquareNeo ExtraBold, 굵은 제목은 heavy), `fill=#rrggbb`, `out=#rrggbb`, `ow=0|1|2`(외곽선 두께), `h=<글자높이px>`, `y=<영역내 y오프셋>`, `thr=<불투명 배경 글자 검출 임계, 기본22>`, `keep=1`(지우지 않고 덧그림), `sp=<자간px>`, `gain=1.15`.
- 한국어 없이 지우기만: 텍스트를 `-`로.
- 조각이 겹칠 때(큰 조각 안에 작은 조각): 같은 영역을 두 번 그리지 않도록 한쪽만 쓰거나, 나머지 부분은 x,y,w,h 상자로 직접 지정.
- 일본어가 없는 조각(영문·숫자·아이콘)은 건드리지 말 것. 아주 작은 장식용 판독불가 글자도 무시.
- 큰 화면 그림(튜토리얼 화면 등)에서 조각이 1개뿐이면 줄 단위 상자를 `prof.py`/`crop.py`로 좌표를 잡아 작성.

## 렌더·확인
- `python -I tools/imgko.py spec_<이름>.txt [hash8 ...]` → `imgout/<md5>.png` 생성.
- `python -I tools/cmp.py z_<이름>.png <hash8> ...` : 원본/결과를 위아래로 비교 이미지 생성 → Read로 보고 확인. `crop.py ... imgout`으로 확대 확인.
- 확인 기준: 원문 잔여물 없음, 글자 잘림 없음, 영역 밖 침범 없음, 읽기 쉬움, 원본과 비슷한 색·굵기. 문제 있으면 사양 수정 후 재렌더.
- `tools/imgko.py`는 공용이므로 수정하지 말 것(문제가 있으면 보고).

## 번역 원칙
- UI 라벨은 짧고 명확하게(조각 폭이 좁으면 축약: 例 ステータス→스테이터스/상태, 装備→장비, 決定→결정, 戻る→돌아가기/뒤로, はい/いいえ→예/아니오).
- 문장형 설명(튜토리얼)은 자연스러운 존댓말 "~합니다".
- 「」 괄호는 그대로 사용 가능. 가운뎃점은 `·`.
